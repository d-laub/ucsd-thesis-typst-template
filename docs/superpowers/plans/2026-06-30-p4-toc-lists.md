# Phase 4 — TOC & List-of Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. When authoring Typst code, also use the `typst-author` skill.

**Goal:** Implement the `TABLE OF CONTENTS` and the seven List-of pages (Figures, Schemes, Tables, Graphs, Abbreviations, Symbols, Supplemental Files) so the preliminary pages that index the dissertation render compliantly with the manual's sample pages (pp. 25–27).

**Architecture:** A new module `lib/lists.typ` exposes inline-call builders (`table-of-contents()`, `list-of-figures()`, …) — same composition style as P2's front-matter pages, **not** a show bundle. The TOC is built **manually by `query`** (no `outline()`): a front-matter pass over registered `<ucsd-toc-entry>` markers (roman page numbers) plus a body/back-matter pass over `query(heading)` (arabic page numbers, with main-matter chapters reconstructed as "Chapter N  title" via a running counter). The List-of-float pages query a unified `<ucsd-float-entry>` marker every float emits. Two small **additive** edits to already-built modules support this: `lib/frontmatter.typ` exports `prelim-heading` and registers TOC entries; `lib/floats.typ` gains a `short:` caption param and emits the unified float marker.

**Tech Stack:** Typst (≥0.15,<0.16 via `pixi`), the vendored TeX Gyre Heros font, P0's `single-spaced` from `lib/blocks.typ`, P2's `prelim-heading`/`register-toc` from `lib/frontmatter.typ`. No pytest — each `tests/*.typ` file is compiled (`pixi run typst compile --font-path fonts --root . tests/<name>.typ build/<name>.pdf`); a failing test is a compile error, a compile **warning**, or a failing in-document `#assert`. A passing test compiles clean with **zero warnings**.

## Global Constraints

- **Full sample fidelity TOC:** lists front-matter pages (Approval, Dedication, Epigraph, Table of Contents, each List-of page, Preface, Acknowledgements, Vita, Abstract) with roman page numbers, then body chapters/sections, then back matter (appendices, references) with arabic page numbers. **Title page & copyright page are NOT listed.**
- **TOC depth 3:** chapters (level 1) + sections (level 2) + subsections (level 3). Main-matter chapter lines = **"Chapter N  <title>"** (title-case label, running counter for N); sections/subsections show title only, unnumbered, indented `(level − 1) × 0.3in`; back-matter level-1 headings (appendix, bibliography) render their body verbatim.
- **Manual query-based TOC** — not Typst `outline()`.
- **Cross-module by label, no imports** (mirrors the `state("ucsd-matter")` contract): front-matter pages emit `[#metadata((title: "<Title Case>")) <ucsd-toc-entry>]`; every float emits `[#metadata((kind, caption)) <ucsd-float-entry>]`. `lib/lists.typ` reads `state("ucsd-matter")` and `counter("ucsd-chapter")` by string.
- **List-of-float entry format:** `"<Supplement> <chap>.<n>: <caption> … <page>"` with dot leaders and the literal supplement word ("Figure"/"Table"/"Scheme"/"Graph").
- **Short caption** via `short:` on `fig`/`tbl`/`scheme`/`graph`; the list uses `short` when provided, else the full caption (author's ≤ 4-line escape hatch). No automatic truncation.
- **Auto-skip empty lists:** each List-of builder renders nothing and registers no TOC entry when its target set / entry list is empty.
- **Reuse `prelim-heading`** (one source of truth for the centered, all-caps, regular-weight preliminary header) — do not duplicate the style in `lib/lists.typ`.
- **Parallel-safety relaxation:** P4 depends on P2/P3 (both complete), so it makes **additive** edits to `lib/frontmatter.typ` and `lib/floats.typ`. It must keep `tests/floats.typ`, `tests/frontmatter.typ`, and `tests/cross-phase.typ` green, and must NOT edit `lib/template.typ`, `lib/blocks.typ`, `lib/pagination.typ`, `pixi.toml`, `tests/smoke.typ`, or `docs/compliance-checklist.md`. No pixi tasks added.

**Verified mechanics (probed against the real modules — rely on these):**
- `numbering("i", ..counter(page).at(e.location()))` on a front-matter marker → its roman page (e.g. `"iii"`).
- `query(heading)` returns **only** body + back-matter headings (front-matter pages use `prelim-heading`, not `heading`); `state("ucsd-matter").at(h.location())` is `"main"` for chapters/sections, `"back"` for appendix/bibliography.
- `counter("ucsd-chapter").at(loc).first()` and `counter(figure.where(kind: k)).at(loc).first()` at a float's (or its adjacent marker's) location give the correct **chapter** and **per-chapter index** — no off-by-one — so `numbering("1.1", chap, n)` reproduces the float number.
- `#bibliography(title: "References")` produces a queryable level-1 `back`-matter heading whose `.body` is `[References]`.

#let _float(
  body,
  caption: none,

  kind: none,

  landscape: false,

    caption: cap,
    kind: kind,
    supplement: supplement,

```typ
// ============================================================================
// Table of Contents & List-of pages (UCSD formatting manual §III pp. 25-27).
//
// Inline-call builders (composed like P2's front-matter pages, NOT a show
// bundle), placed in the front matter between epigraph and preface.
//
// CROSS-MODULE CONTRACTS (by label / string — no imports, like ucsd-matter):
//   <ucsd-toc-entry>  : front-matter pages register their Title-Case title here
//                       (see lib/frontmatter.typ). The TOC's front pass lists them.
//   <ucsd-float-entry>: every float registers (kind, list-caption) here
//                       (see lib/floats.typ). The List-of-float pages consume it.
//   state("ucsd-matter") / counter("ucsd-chapter") : read by string to tell
//                       main-matter chapters from back-matter headings and to
//                       reconstruct "Chapter N" / float numbers.
// ============================================================================

#import "blocks.typ": single-spaced
#import "frontmatter.typ": prelim-heading, register-toc

// One dot-leader line: title … page. Single-spaced internally (so a wrapped
// entry stays single), with the inherited body spacing separating entries.
// first-line-indent reset so the 0.5in body indent does not push entries right.
#let _toc-line(title, page, indent: 0pt) = {
  set par(leading: 0.65em, first-line-indent: 0pt)
  pad(left: indent)[#title#box(width: 1fr, repeat[.])#page]
}

// TABLE OF CONTENTS — manual, query-based (not outline()).
#let table-of-contents() = {
  pagebreak(weak: true)
  prelim-heading("Table of Contents")
  register-toc("Table of Contents")
  v(2em)
  context {
    // Front-matter pass: registered markers, roman page numbers, document order.
    for e in query(<ucsd-toc-entry>) {
      _toc-line(e.value.title, numbering("i", ..counter(page).at(e.location())))
    }
    // Body + back-matter pass: query(heading) returns ONLY body/back headings
    // (front matter uses prelim-heading, not heading). Arabic page numbers.
    let chap = 0
    for hd in query(heading) {
      if hd.level > 3 { continue }
      let pg = numbering("1", ..counter(page).at(hd.location()))
      if hd.level == 1 and state("ucsd-matter").at(hd.location()) == "main" {
        // Main chapter: reconstruct "Chapter N  <title>" with a running count
        // (sidesteps any counter.at timing concern).
        chap += 1
        _toc-line([Chapter #chap#h(1em)#hd.body], pg)
      } else {
        // Sections/subsections (unnumbered, indented) and back-matter level-1
        // headings (appendix, bibliography) — title verbatim.
        _toc-line(hd.body, pg, indent: (hd.level - 1) * 0.3in)
      }
    }
  }
}
```
